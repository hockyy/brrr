\begin{abstract}
Draft. Brrr is an intermediate representation and compiler framework designed for
agent-driven compilation. Rather than operating agents on IRs built for human pass
authors, we redesign the IR itself around agent affordances: stable node identity that
survives transformations and serialization, definitions as runtime data, transactional
deltas with provenance, and a canonical, token-lean text format. We ground the design
in a survey of production and research IRs across language, tensor, hardware, and
database compilers, which shows that expressiveness across IR forms is largely
equivalent and that identity, data-defined definitions, and provenance are the
unclaimed axes.
